📋 Cheat Sheet de Redes

Resumo rápido de comandos, conceitos e valores essenciais para revisão.

🏗️ Modelos OSI e TCP/IP

Modelo OSI (7 camadas)

  1. 7. Aplicação: HTTP, FTP, DNS - PDU: Dados
  2. 6. Apresentação: Criptografia, compressão - PDU: Dados
  3. 5. Sessão: Controle de diálogo - PDU: Dados
  4. 4. Transporte: TCP/UDP - PDU: Segmento/Datagrama
  5. 3. Rede: IP, roteamento - PDU: Pacote
  6. 2. Enlace: Ethernet, MAC - PDU: Quadro
  7. 1. Física: Bits, cabos - PDU: Bits

Modelo TCP/IP (4 camadas)

  1. 4. Aplicação: Combina camadas 5-7 OSI
  2. 3. Transporte: TCP/UDP (= OSI 4)
  3. 2. Internet: IP, ICMP (= OSI 3)
  4. 1. Acesso à Rede: Ethernet, Wi-Fi (= OSI 1-2)

Mnemônico OSI (cima→baixo): A P S T R E F

🌐 Endereçamento IP

IPv4 Privado (RFC 1918)

  • 10.0.0.0/8 (10.0.0.0 - 10.255.255.255)
  • 172.16.0.0/12 (172.16.0.0 - 172.31.255.255)
  • 192.168.0.0/16 (192.168.0.0 - 192.168.255.255)

CIDR Comum

  • /8 = 255.0.0.0 → 16.777.214 hosts
  • /16 = 255.255.0.0 → 65.534 hosts
  • /24 = 255.255.255.0 → 254 hosts
  • /30 = 255.255.255.252 → 2 hosts (p2p)

IPv6

  • Global Unicast: 2000::/3 (roteável)
  • Link-Local: fe80::/10 (só rede local)
  • Unique-Local: fc00::/7 (= privado IPv4)
  • Loopback: ::1

Simplificação: omitir zeros à esquerda; substituir bloco de zeros consecutivos por :: (uma vez apenas).

⚡ TCP vs UDP

TCP (Transmission Control Protocol)

  • Confiável: Garante entrega e ordem
  • Handshake: SYN → SYN-ACK → ACK
  • Controle de fluxo: Gerencia velocidade
  • Uso: HTTP/S, FTP, SMTP, SSH

UDP (User Datagram Protocol)

  • Rápido: Sem garantia de entrega
  • Sem conexão: Envia e esquece
  • Baixa latência: Ideal para tempo real
  • Uso: DNS, streaming, VoIP, jogos

💻 Comandos Essenciais (Linux)

Rede e Interfaces

# Ver interfaces e IPs ip a ip addr show # Ver rotas ip route ip route show # Adicionar rota estática ip route add 192.168.2.0/24 via 192.168.1.1 # Ver tabela ARP ip neigh arp -a

Conexões e Portas

# Ver conexões TCP/UDP ss -tulpn netstat -tulpn # Portas em escuta ss -ltn lsof -i -P -n | grep LISTEN # Conexões estabelecidas ss -tn state established

Diagnóstico

# Ping (ICMP) ping -c 4 8.8.8.8 # Traceroute (caminho de pacotes) traceroute google.com mtr google.com # Melhor que traceroute # Testar porta TCP nc -zv example.com 443 telnet example.com 443

Captura de Pacotes

# Capturar todo tráfego sudo tcpdump -i eth0 -w capture.pcap # Capturar porta específica sudo tcpdump -i eth0 port 80 -n # Ver handshake TCP (SYN) sudo tcpdump -i eth0 'tcp[tcpflags] & tcp-syn != 0' # Ler pcap tcpdump -r capture.pcap tshark -r capture.pcap

🔒 Proxies & VPNs

Proxies

  • Transparent: Cliente não sabe (captive portal)
  • Anonymous: Oculta IP, revela proxy
  • Elite: Oculta IP e proxy
  • Forward: Para clientes (filtro/anonimato)
  • Reverse: Para servidores (LB/SSL term)
# SOCKS5 via SSH ssh -D 1080 user@proxy.example.com # Usar proxy HTTP curl -x http://proxy:3128 https://example.com # Usar SOCKS5 curl --socks5-hostname localhost:1080 https://example.com

VPNs

  • IPSec: Site-to-site, complexo
  • OpenVPN: SSL/TLS, versátil, 1194/UDP
  • WireGuard: Moderno, rápido, 51820/UDP
  • Split-tunnel: Só tráfego específico
  • Full-tunnel: Todo tráfego via VPN
# WireGuard up/down wg-quick up wg0 wg-quick down wg0 # Ver status WireGuard sudo wg show

🕵️ Tor & Anonimidade

Tor Basics

  • 3 saltos: Guard → Middle → Exit
  • Cada camada descriptografa 1 nível (onion)
  • Exit node vê tráfego não-criptografado
  • Hidden services: .onion
# Usar Tor SOCKS5 (porta 9050) curl --socks5-hostname 127.0.0.1:9050 https://check.torproject.org/ # Com torsocks (wrapper) torsocks curl https://example.com

Leaks Comuns

  • DNS leak: DNS não vai pelo VPN/Tor
  • WebRTC leak: Revela IP real via browser
  • IPv6 leak: VPN só rota IPv4

Teste: browserleaks.com/webrtc, ipleak.net

Mitigação: DNS over HTTPS, desabilitar WebRTC (media.peerconnection.enabled=false no Firefox), desabilitar IPv6.

🔥 Firewalls

Tipos

  • Stateless: Inspeciona pacotes isolados
  • Stateful: Mantém tabela de estados
  • Proxy/App: Camada 7, DPI
  • NGFW: Stateful + IPS + App control

iptables (básico)

# Listar regras iptables -L -n -v # Permitir SSH iptables -A INPUT -p tcp --dport 22 -j ACCEPT # Bloquear IP iptables -A INPUT -s 1.2.3.4 -j DROP # Política padrão (negar tudo) iptables -P INPUT DROP iptables -P FORWARD DROP

🔍 Detectabilidade

Sinais de Proxy/VPN

  • TTL anomaly: Valor inesperado (proxy adiciona hop)
  • TLS fingerprint: Inconsistência SO/cliente
  • IP blacklists: IPs conhecidos de VPN

DNS Tunneling

  • Queries muito longas (60+ chars)
  • Alta frequência (100s/min)
  • Alta entropia (aleatório)
  • Tipos raros (TXT, NULL)

💡 Dicas de Revisão

  • Lembre-se do three-way handshake TCP: SYN → SYN-ACK → ACK (cliente→servidor→cliente).
  • Subnetting: /24 = 254 hosts, /30 = 2 hosts (P2P links).
  • NAT: Traduz IPs privados para públicos (geralmente no roteador/firewall).
  • DMZ: Zona intermediária entre internet e LAN interna (servidores públicos).
  • Proxy vs VPN: Proxy = camada 7 (app); VPN = camada 3 (rede, todo tráfego).
  • Tor: 3 saltos, camadas de cifragem, exit node vê tráfego não-HTTPS.
  • DNS leak: Testar com dnsleaktest.com ou ipleak.net.

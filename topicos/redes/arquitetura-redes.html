Arquitetura de Redes: OSI e TCP/IP

Os pilares que sustentam toda a comunicação na internet.

O que são Modelos de Referência?

Imagine tentar construir um carro sem uma planta. Cada engenheiro faria uma peça de um jeito, e elas jamais se encaixariam. Modelos de referência, como o OSI e o TCP/IP, são as "plantas" para a comunicação em rede. Eles dividem o complexo processo de enviar dados em camadas menores e gerenciáveis. Cada camada tem uma função específica e só se comunica com a camada imediatamente acima ou abaixo, garantindo que equipamentos de diferentes fabricantes possam conversar entre si.

O Modelo OSI (Open Systems Interconnection)

O Modelo OSI é um modelo conceitual de 7 camadas criado pela ISO para padronizar as funções de um sistema de telecomunicação. Embora a internet moderna use o modelo TCP/IP na prática, o OSI é fundamental para o estudo acadêmico por ser mais detalhado e didático.

7. Camada de Aplicação

A camada mais próxima do usuário. Fornece a interface para que os aplicativos acessem os serviços de rede.

PDU: Dados (Data)

Protocolos: HTTP, HTTPS, FTP, SMTP, DNS.

Função: Permitir que softwares enviem e recebam informações de forma significativa para humanos.

6. Camada de Apresentação

Atua como um "tradutor". Converte os dados para um formato que a camada de aplicação possa entender. Responsável pela criptografia, compressão e formatação.

PDU: Dados (Data)

Função: Formatação de dados (ex: ASCII, JPEG, MPEG), Criptografia (SSL/TLS).

5. Camada de Sessão

Estabelece, gerencia e encerra as conexões (sessões) entre computadores.

PDU: Dados (Data)

Função: Controle de diálogo (quem fala e quando), sincronização e recuperação de falhas.

4. Camada de Transporte

Responsável pela entrega confiável ou não dos dados entre os hosts de origem e destino. Segmenta os dados e controla o fluxo.

PDU: Segmento (TCP) / Datagrama (UDP)

Protocolos: TCP (confiável, orientado à conexão), UDP (rápido, sem conexão).

3. Camada de Rede

Decide o caminho físico que os dados tomarão. Responsável pelo endereçamento lógico (IP) e roteamento.

PDU: Pacote (Packet)

Protocolos: IP (IPv4, IPv6), ICMP.

Dispositivos: Roteadores.

2. Camada de Enlace de Dados

Define como os dados são formatados para transmissão em um meio físico. Lida com endereçamento físico (MAC Address) e detecção de erros.

PDU: Quadro (Frame)

Protocolos: Ethernet, Wi-Fi.

Dispositivos: Switches.

1. Camada Física

Define as especificações elétricas e físicas dos dados. Transmite os bits brutos pela rede.

PDU: Bits

Meios: Cabos (Cobre, Fibra Óptica), Rádio (Wi-Fi, Bluetooth).

Dispositivos: Hubs, Repetidores.

OSI vs. TCP/IP: A Batalha dos Modelos

O modelo TCP/IP é o que a internet realmente usa. É mais simples, com apenas 4 camadas. Ele combina as funções das camadas superiores do OSI, sendo mais prático e eficiente.

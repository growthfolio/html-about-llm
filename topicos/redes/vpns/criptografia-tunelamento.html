Criptografia e Tunelamento em VPNs

Os pilares da segurança e privacidade em redes privadas virtuais.

O Papel da Criptografia

A criptografia é o coração de uma VPN, garantindo que os dados transmitidos sejam ininteligíveis para qualquer um que tente interceptá-los. Ela transforma informações legíveis (texto puro) em um formato codificado (cifrado) que só pode ser decodificado com a chave correta.

Criptografia Simétrica

Usa uma única chave para criptografar e descriptografar. É rápida e eficiente, ideal para criptografar grandes volumes de dados. A chave deve ser compartilhada de forma segura entre as partes.

Ex: AES, DES

Criptografia Assimétrica

Usa um par de chaves (pública e privada). A chave pública criptografa, e a privada descriptografa (e vice-versa). É mais lenta, usada para troca segura de chaves simétricas e autenticação.

Ex: RSA, ECC

Integridade e Autenticidade

Além da confidencialidade (garantida pela criptografia), as VPNs precisam assegurar a integridade dos dados (não foram alterados) e a autenticidade das partes (quem está comunicando é quem diz ser).

Funções de Hash

Transformam dados de qualquer tamanho em um "resumo" de tamanho fixo (hash). Qualquer alteração mínima nos dados resulta em um hash completamente diferente. Usado para verificar a integridade dos dados.

Ex: SHA-256, MD5 (obsoleto para segurança)

Assinaturas Digitais

Usam criptografia assimétrica e funções de hash para verificar a autenticidade e a não-repúdio. O remetente assina o hash da mensagem com sua chave privada; o receptor verifica com a chave pública do remetente.

Tunelamento: Criando um Caminho Privado

Tunelamento é o processo de encapsular pacotes de dados dentro de outros pacotes. É como colocar uma carta dentro de outro envelope antes de enviá-la. Em uma VPN, os dados originais são criptografados e depois colocados dentro de um novo pacote, que então é enviado pela rede pública (internet).

Como funciona:

  • Encapsulamento: O pacote de dados original (com seu cabeçalho e carga útil) é criptografado.
  • Novo Cabeçalho: Um novo cabeçalho (do protocolo de tunelamento da VPN) é adicionado ao pacote criptografado. Este novo cabeçalho contém as informações de roteamento necessárias para atravessar a rede pública até o servidor VPN.
  • Transmissão: O pacote "tunelado" é enviado pela internet. Para observadores externos, parece ser apenas tráfego criptografado indo do seu dispositivo para o servidor VPN.
  • Desencapsulamento: No servidor VPN, o novo cabeçalho é removido, o pacote interno é descriptografado, e o pacote de dados original é encaminhado para seu destino final (por exemplo, um site na internet ou um servidor na rede interna da empresa).

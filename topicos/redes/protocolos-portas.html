Protocolos e Portas: A Linguagem da Rede

Entendendo como os serviços conversam e se organizam.

TCP vs. UDP: A Escolha entre Confiabilidade e Velocidade

Na camada de Transporte, dois protocolos dominam: TCP e UDP. A escolha entre eles define como os dados são enviados e recebidos, com um trade-off fundamental.

TCP (Transmission Control Protocol)

O protocolo confiável. Garante que todos os pacotes cheguem na ordem correta e sem erros.

  • Orientado à conexão: Usa o three-way handshake (SYN, SYN-ACK, ACK) para estabelecer uma conexão antes de enviar dados.
  • Controle de fluxo: Gerencia a quantidade de dados enviados para não sobrecarregar o receptor.
  • Confirmação e retransmissão: Se um pacote se perde, o TCP o reenvia.
  • Casos de uso: Navegação web (HTTP/S), email (SMTP), transferência de arquivos (FTP). Onde a integridade dos dados é crítica.

UDP (User Datagram Protocol)

O protocolo veloz. Envia os dados e não olha para trás. Não há garantia de entrega ou ordem.

  • Não orientado à conexão: Simplesmente envia os pacotes (datagramas) para o destino.
  • Sem controle: Não há controle de fluxo, confirmação ou retransmissão.
  • Baixa latência: Muito mais rápido por não ter toda a sobrecarga do TCP.
  • Casos de uso: Streaming de vídeo/áudio, jogos online, chamadas de voz (VoIP), DNS. Onde a velocidade é mais importante que a perda ocasional de um pacote.

Portas Lógicas: Os "Apartamentos" de um Endereço IP

Se o endereço IP é o endereço de um prédio, as portas são os números dos apartamentos. Elas permitem que um único dispositivo execute múltiplos serviços de rede simultaneamente. Uma porta é um número de 16 bits (de 0 a 65535). A combinação de um IP e uma porta (ex: 192.168.1.1:443) é chamada de socket.

  • Portas 0-1023: Bem Conhecidas (Well-known ports), reservadas para serviços padrão (HTTP, FTP, etc).
  • Portas 1024-49151: Registradas, usadas por aplicações específicas.
  • Portas 49152-65535: Dinâmicas ou Privadas, usadas para conexões de saída temporárias.

Protocolos de Aplicação Essenciais

DNS (Domain Name System) - Porta 53 (UDP/TCP)

É a "lista telefônica" da internet. Traduz nomes de domínio legíveis por humanos (como google.com) para endereços IP compreendidos por máquinas. As consultas usam UDP pela velocidade, mas transferências de zona (sincronização entre servidores DNS) usam TCP pela confiabilidade.

HTTP/HTTPS (Hypertext Transfer Protocol) - Portas 80/443 (TCP)

O protocolo da World Wide Web. Define como as mensagens são formatadas e transmitidas entre seu navegador e os servidores web. O HTTPS é a versão segura, que criptografa a comunicação usando SSL/TLS.

DHCP (Dynamic Host Configuration Protocol) - Portas 67/68 (UDP)

Automatiza a configuração de rede. Quando você se conecta a uma rede, seu dispositivo envia uma mensagem em broadcast, e um servidor DHCP responde, fornecendo um endereço IP, máscara de sub-rede, gateway padrão e servidores DNS.
